# Privacy

StepsTracker processes email addresses, physical profile data, and daily activity. Weight, height, date of birth, and physiological sex are used exclusively to estimate distance and calories. The resulting values are estimates, not medical measurements.

Users can revoke Android permissions without deleting data that has already been synchronized. Account deletion cascades to the profile, devices, tokens, and intervals. Server logs do not include credentials, authentication payloads, or detailed step data.
